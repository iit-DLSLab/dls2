# Task
A task is a periodic application that can any kind of work and publish any data until its duties are concluded. Once the task is completed, it goes back to the _idle_ state. For example, _standing up_ or _pick up the bottle_ could be tasks that can be activated, they ca do some computation, and than they can stop (i.e. come back to idle state).

# How to create and run a task
To create a task, you can follow any of the examples in the [tasks]() repository.

To run a task, you can use the `Supervisor::runTask <task_name>` console command.
