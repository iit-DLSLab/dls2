`CMake` exposes a `make package` target that can wrap all the `install` commands
into a Debian. It is required that the CI/CD pipelines produce such Debians for
deployment. The following code snippet can be used to produce such output:

```txt
set(CPACK_PACKAGE_NAME              "DESIRED_NAME_OF_PACKAGE")
set(CPACK_PACKAGE_VERSION_MAJOR     ${PROJECT_VERSION_MAJOR})
set(CPACK_PACKAGE_VERSION_MINOR     ${PROJECT_VERSION_MINOR})
set(CPACK_PACKAGE_VERSION_PATCH     ${PROJECT_VERSION_PATCH})
set(CPACK_PACKAGE_VENDOR            "dlslab")
set(CPACK_PACKAGE_CONTANCT          "EMAIL_OF_PACKAGE_MAINTAINER")
set(CPACK_VerBAGTIM_VARIABLES       ON)
set(CPACK_GENERATOR                 "DEB")
set(CPACK_DEBIAN_PACKAGE_MAINTAINER "NAME_OF_PACKAGE_MAINTAINER")
set(CPACK_DEB_COMPONENT_INSTALL     ON)
set(CPACK_DEBIAN_FILE_NAME          "DESIRED_NAME_OF_DEBIAN_FILE_NAME-${PROJECT_VERSION}.deb")
include(CPack)
```

Note that this needs to be the last thing inside your CMakeLists project tree.
It needs to be called _after_ all install commands. `CPack` must be included
after all its variables are set.

When using ROS, you may have the issue that catkin automatically tries to
install unnecessary files. Explicitly setting the package name like done above
also means that the debian generated by catkin's unnecessary files will
overwrite the debian generated by the project. If this happens, add the
following two lines _before_ calling `include(CPack)`:

```txt
get_cmake_property(CPACK_COMPONENTS_ALL COMPONENTS)
list(REMOVE_ITEM CPACK_COMPONENTS_ALL "Unspecified")
```

This works, because the project is split into different components. Calls to
commands such as `dls_install_controller` will behind the scenes install its
targets to the correct component. Catkin, on the other hand, does not follow the
recommended practice of splitting `install` commands into different components.
In this case `CMake` will set it to the default component named `Unspecified`.
The above two lines essentially tell `CMake` to install all components except
the `Unspecified` component.
